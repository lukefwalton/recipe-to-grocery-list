# Recipe to Grocery List

A local-first iOS app that turns recipes into a grocery list.

Same family as [Private Workout Logger](https://github.com/lukefwalton/workout-logger) and [A New Word Every Day](https://github.com/lukefwalton/a-new-word-every-day): SwiftUI, on-device, no account, no tracking.

## Status

First commit. App code is not here yet.

## Building

The Xcode project will be generated with [XcodeGen](https://github.com/yonaskolb/XcodeGen), same as the other apps. Setup notes will land here with the first project files.
